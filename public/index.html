✉️ Gmail — brouillons de relance

Comment obtenir un mot de passe d'application ?
  1. Active la validation en 2 étapes sur ton compte Google.
  2. Va sur myaccount.google.com/apppasswords.
  3. Donne un nom (ex. « CRM candidatures ») puis copie le code de 16 lettres ici.

Ce n'est pas ton vrai mot de passe Gmail : il sert uniquement à déposer les brouillons, et tu peux le révoquer à tout moment. Il reste sur ton ordinateur (data/settings.json) et n'est jamais renvoyé à la page.
